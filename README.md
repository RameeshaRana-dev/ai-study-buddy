# 🤖📚 AI Study Buddy

An AI-powered flashcard and quiz generator built with TypeScript, Vite, and the Gemini API. Paste your notes or a topic, and it generates flip-card flashcards and multiple-choice quizzes with difficulty levels, score tracking, and quiz history.

## 🔧 Features
- Paste notes/topic and generate 5 AI-powered flashcards with click-to-flip UI
- Generate a 5-question multiple choice quiz with difficulty levels (Easy/Medium/Hard)
- Score tracking, progress bar, and question counter during the quiz
- Quiz result screen with performance-based feedback
- Quiz history panel — view and delete past attempts
- Dark/Light mode toggle
- Fully responsive design (mobile and desktop)
- API key secured via a serverless backend function (not exposed to the client)

## 🛠️ Technologies Used
- TypeScript
- Vite
- HTML/CSS
- Gemini API (Google Generative Language API)
- Vercel Serverless Functions

## 💡 Concepts Used
- Async/await and fetch API for AI integration
- DOM manipulation without a framework
- localStorage for persisting flashcards, quiz results, and history
- TypeScript interfaces for structured data (Flashcard, QuizQuestion, HistoryEntry)
- Responsive design using media queries
- Serverless functions for secure API key handling
